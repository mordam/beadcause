# v101 — the space picker is one control, and a v100 stylesheet makes it disappear (bc-ka5y.34)

The picker was three boxes in one control: a `.spacepick-shown` span holding a label cut
to twelve characters, a `.spacepick-caret`, and the `<select>` laid over both of them at
`opacity: 0`. The span is gone. What you read is the select's own selected option now,
capped by a `max-width` and ellipsised past it, and the select is the box you see as well
as the one you tap.

Two shell files move together, and a phone caches them separately. `public/spacebar.js`
stops emitting `.spacepick-shown` and stops writing a second string into it — no
`shorten`, no `SHOWN_MAX`, no `shortLabel()` on `window.beadcause.space`. `public/style.css`
deletes `.spacepick-shown` and moves everything that was on it — border, radius, surface,
the 14px/1.2 longhands, the narrowed accent, the focus ring — onto `.spacepick select`,
which stops being `position: absolute; inset: 0; opacity: 0` and becomes an ordinary,
visible box with `max-width: 130px`, `overflow: hidden` and `text-overflow: ellipsis`.

**A v100 stylesheet beside a v101 script is the mixed cache that matters, and what it draws
is nothing at all.** The span the old rules style is not in the markup, so they match
nothing; the select is still `position: absolute; inset: 0; opacity: 0; border: 0` against
a `.spacepick` whose only remaining in-flow child has been taken out of flow — so the
control collapses to no width, invisible, and the absolutely-positioned select collapses
with it. The bar draws a mark and then empty space. The picker is not merely unstyled: it
is **gone and untappable**, on a screen whose lists are still narrowed to whatever the
filter says, with no control left to widen them and no text anywhere saying which repo you
are in. That is the app's one piece of context silently deleted, and a reload of the page
does not fix it — only a new shell does.

The reverse pair — a v101 stylesheet under a v100 script — is bad in the ordinary way rather
than the dangerous one. The span is still drawn and has no rules, so the cut-down label is
bare inline text with no surface; the select beside it is now a real visible box with a
border and a background, in flow rather than laid over anything, so the picker reads as the
same space twice, side by side, and the pair is wide enough to push the bar onto a second
row. Ugly, honest, and every control still does what it says.
