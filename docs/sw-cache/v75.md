# v75 — the scope switch leaves the filter panel for the chrome (bc-khoe.24)

`Human / Both / Agent` was the `Show` group inside the collapsed panel on Home. It is a
segmented switch on the row itself now, drawn by a new file, `public/filterpills.js`.

**The pair that breaks is a v74 `index.html` under a v75 `app.js`, and it breaks by
subtraction.** `mountFilters` hands the panel `[beadGroup]` where it used to hand it
`[scopeGroup, beadGroup]`, and hands the scope to
`window.beadcause.filterPills.mount(...)` instead. A cached v74 page has no
`<script src="/filterpills.js">` tag, so that global does not exist — the call is
`?.`-guarded and returns quietly, which is exactly the failure mode worth a version
number: **the phone loses the scope control altogether**. Not a broken button, not a
console error: a Home with no way to say whether it is showing you the questions or the
live beads, whichever of the three it happens to have stored. The list it draws is
correct for the scope on disk, so nothing looks wrong, and the one thing that could tell
you what it is showing is gone.

The reverse — a v75 `index.html` under a v74 `app.js` — is the mixture that is merely
noisy: the new script tag loads, `filterPills.mount` is never called because the old
`app.js` does not know about it, and the scope is where it always was, inside the panel.
That direction is the app as it was.

Two smaller couplings ride along and neither would have owed a bump alone:

- **`public/style.css`.** `.filterpills` is new and `.filters` gains
  `align-items`/`gap`; `.filter-menu` gains `min-width: 0` so the summary line ellipsises
  rather than shoving the row past a 360px screen. A v74 stylesheet under a v75 page
  draws the switch unstyled-as-a-row — the chips are still `.chip-row.scopes` and still
  banded, so it is legible; it is the gap between the two controls and the summary's
  refusal to shrink that go.
- **`.chip-row.scopes`'s `flex-wrap: nowrap`** was scoped to `.filter-panel` and is not
  any more, because the switch has two homes now. At v74 that rule does not reach the new
  row, and a narrow enough screen would put `Agent` on a line of its own — a segmented
  control that wraps is three chips again, which is the look this switch has never had.

`public/sw.js` also gains `/filterpills.js` in `SHELL`, for the reason the panel beside
it is there: the moment this file is wanted is the moment the phone cannot reach the
daemon, and a shell that can draw Home but not say which slice of the tracker Home is
showing is the worst version of being offline.
