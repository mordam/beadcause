# v20 — the answer box grew a microphone

`/dictate.js` is a new path and app.js asks it, at render time, whether to draw the mic
at all — so a phone holding v18's cached app.js beside v20's would draw an answer box
with no way to dictate into it, and a phone holding the new app.js without the new file
would draw one every time and never listen. They have to arrive together, which is what
a cache version is for.
