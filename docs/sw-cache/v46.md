# v46 — the terminal's door moved off the inbox header and onto /admin (bc-l8jp.2)

No new path: every file involved is already in `SHELL`. The bump is owed because the move
is a **pair of precached documents** — `index.html` without the ⌨️ and `admin.html` with
the card that replaces it — and either one cached against the other is broken rather than
merely older.

A phone holding v45's cached `/` beside v46's `/admin` shows the button in *both* places,
which is the one state the change exists to remove. The other way round is worse: v45's
`/admin` beside v46's `/` has **no standing way into the terminal at all**, because the
header button it used to be reached by is exactly what this version takes away. `/terminal`
still answers, so a bookmark survives, but nothing in the chrome points at it.

`style.css` is the third file in the set. `.admin-door` is what makes the new anchor a
button; a v45 stylesheet under v46's `admin.html` draws the only door as a line of blue
text at the bottom of a card.

**On the renumbering:** this note argued v28 when it was written on 2026-08-11, in the era
when the argument lived as a comment block at the top of `public/sw.js`. The branch was
closed over without landing (bc-4ztq, under bc-xl7n.1) and sat 452 commits behind while
main went to v45 and moved every note into this directory. The prose is the original
argument, renumbered and re-pointed at v45 as the predecessor it is actually shipping
against — which is the `git mv` half of the conflict procedure in `public/sw.js`, done
across a downmerge rather than between two live branches.
