# v50 — the app updates itself (bc-jznr)

`public/update.js` joins the shell, and `public/stream.js` gains the thing it listens on.

## Why this one is a bump rather than an additive skip

`update.js` is a new file and nothing else calls into it, which is the shape that
legitimately skips a bump — a cached page without the `<script>` tag is the app exactly
as it was. That is not the whole change:

- **`stream.js` gained `listen`, and `update.js` calls it.** Those are two files that
  both already existed, one gaining a member and the other gaining a call to it — the
  mixed pair `lib/swbump.js` calls a *failure* rather than an advisory. A phone holding
  v49's `stream.js` beside v50's `update.js` gets `window.beadcause.stream.listen` as
  `undefined`. It is reached through `?.` and so would not throw, which is worse rather
  than better: the app would sit there having quietly stopped listening for the deploys
  it exists to hear, on exactly the devices least likely to be looked at.
- **`style.css` carries the two controls** — `.app-update` and `.app-update-ask` — and
  the six pages carry the tag that loads the script that draws them. A page cached
  without the stylesheet's new rules would draw an unstyled button in the top bar.

## What is in it

- `public/update.js` — new; the reload after a deploy that moved `public/`, and the
  Android shell's download → ask → install → restart.
- `public/stream.js` — `listen(fn)`, so a script shared by every page can hear the
  events without opening a second parked poll.
- `public/style.css` — `.app-update` (the top-bar button) and `.app-update-ask` (the ask
  once the APK has landed).
- `public/monitor.js` — the Ship strip on the advocate card; it draws through `.release`,
  which the stylesheet already had for the PR board.
- `index`, `monitor`, `history`, `endorse`, `console`, `admin` — the `<script>` tag.

This was written as v49 and lost the race: bc-p49x.2 took that number, and the add/add
conflict on `docs/sw-cache/v49.md` at downmerge is what said so — which is the mechanism
sw.js's header describes working exactly as intended. Both notes are kept and this one is
renumbered, because a gap is not available: `test/swcache.mjs` refuses one.

Worth noting what did *not* say so. Both branches wrote the identical string to
`const CACHE`, so that line merged clean and in silence — two versions' worth of change
under one cache key, and no conflict anywhere near it. The `vNN.md` filename is the only
thing in this repo that catches that.
