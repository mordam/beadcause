# v24 — the endorsement queue

`/endorse` and its script are new paths, and index.html grew the 🗳️ that opens it — so
a phone holding an older cached inbox would have neither the door nor the page behind
it, and one holding the old `/` beside a v24 daemon would show a top-bar button that
404s out of the cache the moment the tailnet is slow. The page they have to arrive with
is the whole point of the version.
