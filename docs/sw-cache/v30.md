# v30 — every view moved onto the delta stream

`/stream.js` is a new path *and* all five standing pages mount it in place of the
`setInterval` they used to refresh on — so a phone holding v29's cached admin.js,
monitor.js or prs.js beside a v30 daemon still has the ten-second sweep this removed,
and one holding v30's scripts without the file has four pages that never refresh at all:
the timer is deleted in the same change that adds the poll, and nothing else brings a
row up to date. That is the strictest version of what a cache version is for — the
failure is not a broken page, it is a page that looks right and is quietly hours out of
date.
