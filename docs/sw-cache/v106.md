# v106 — the docket, and every card's way to it (bc-it26z)

A new page — `/docket`, an epic's whole arc in the order it happened — plus the links to
it from the cards that were missing the context it carries.

| half | what is new |
|---|---|
| `public/docket.html`, `public/docket.js` | the page, added whole |
| `public/style.css` | the `.dk-*` block: the head, the phases, the map, the day-folded stream and the index |
| `public/app.js` | `docketUrl`, and the link on the agent card's actions row, in the question card's brief, and on every bead row of the epic board |
| `public/drawer.js` | `/docket`, `/dockets` and `/epic` in `DETAIL`, so the page opens over the list you were reading rather than leaving it |
| `public/sw.js` | those paths in `SHELL` |

**The pairing that owes the bump is `style.css` beside a page that is entirely new.**
`public/docket.js` is added whole, so it is never half of a mixed pair on its own — a
cache from before this branch has neither it nor its markup. What that reasoning misses is
the *third* file: `style.css` is in `SHELL`, it is where every rule the new page draws
against lives, and a phone holding v105's copy would fetch the new page and the new script
and then render them against a stylesheet that has never heard of `.dk-day`, `.dk-ev` or
`.dk-row`. That is not a missing accent. The stream loses its clock gutter and its
indent, the fold control loses the pill that makes it read as a control, and the focused
bead loses the one mark that says *this is where your card came from* — which is the
single thing the page was built to say. It looks like a working page, which is this
version file's whole subject.

**`drawer.js` beside `app.js` is the second pairing, and it is the quiet one.** The cards
now link to `/docket`, and whether that link opens *in the drawer* or navigates the tab
away is decided by `DETAIL` in `drawer.js`. A phone holding the old `drawer.js` under the
new `app.js` still reaches the docket — the anchor works, it is a real page — but it
leaves the inbox to get there, which for a link drawn on a card you are part-way through
answering is the failure the drawer exists to prevent.

**One thing here is deliberately *not* an argument for the bump.** `/docket` is also in
`SHELL` under its own alias, and a phone that never gets the new `sw.js` simply never
precaches it — that is a page fetched from the network on first open, which is the
ordinary state of every page in this app before it has been visited. Nothing breaks; it
is only slower once.
