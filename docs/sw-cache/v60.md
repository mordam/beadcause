# v60 — the cancelled fold grew a second list (bc-0i27.19)

A cancel record for a JIRA ticket never expires, and the fold that draws cancelled
tickets is a filter over what the poller answered — so a ticket cancelled and then
resolved, reassigned, or moved out of the configured projects left a record on disk with
no screen anywhere that could name it. The fold now carries a second list at its foot:
the records with no ticket left, each with a **Drop**. Two files move together.
`public/app.js` gains `strandedCancelsHtml`, which draws a `.jira-orphans` block of
`.jira-orphan` lines; `public/style.css` gains the six selectors that lay them out.

**A v59 stylesheet beside a v60 app.js is the pair that matters.** None of
`.jira-orphans`, `.jira-orphans-why`, `.jira-orphan`, `.jira-orphan-what`,
`.jira-orphan-key`, `.jira-orphan-ws` or `.jira-orphan-when` exists at v59, so the block
renders as browser defaults: the explanatory paragraph and every record run together as
undifferentiated text with no separators and no muted colour, the workspace and the
timestamp sit inline against the ticket key as one unbroken sentence, and — the one that
actually misleads — the Drop button inherits `.secondary`, which is `flex: 1`, from a
stylesheet that never got the `flex: 0 0 auto` override. Stretched the width of a phone
beside a line of plain text, it reads as the whole line being one button. Nothing throws,
and everything is tappable; it just looks like a rendering fault in the section whose
entire purpose is to be legible about records that were previously invisible.

The other way round is harmless: a v60 stylesheet over a v59 app.js styles selectors that
appear nowhere on the page.

Nothing else moves. `state.strandedCancels` defaults to `[]` and is only adopted when the
payload carries the field, so a v60 page against a daemon that predates the route draws
exactly the fold it drew before.

The fetch handler is network-first, so this pair only exists on an offline or flapping
load and heals on the next online one. Bumped for the usual reason: the cheap half is a
stale stylesheet, and a missing stylesheet is not loud.
