# v21 — Google sign-in

Nothing new in the shell — the login page is deliberately NOT cached, see fetchAndStore
— but a phone holding v20's cache has app.js from before `needCredential` existed, which
pops the token dialog at a browser that is signed in perfectly well. The version is also
what evicts anything a v20 worker cached while the session had expired: it was
network-first, so a redirect to /login could have been stored under `/`.
