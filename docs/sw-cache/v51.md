# v51 — the filter panel comes out of the inbox (bc-nib3.3)

`public/filtermenu.js` is new and joins the shell; `public/inboxfilter.js` is what is
left of the inbox's filter once the panel has been lifted out of it, and the History tab
mounts the same panel over four filters of its own.

## Why this one is a bump

`lib/swbump.js` reads this branch as an advisory rather than a failure, and it is wrong
about it — worth writing down, because the shape it cannot see will come round again. Its
test is a *call on a member the other half lacks*, between two files that both already
existed. Here the coupling runs through an HTML `<script>` tag:

- **`inboxfilter.js` no longer draws a panel — it mounts one.** Its `mount()` reaches
  `window.beadcause.filterMenu.mount`, and the only thing that puts `filterMenu` there is
  the new file. A phone holding v50's `index.html`, which has no `<script
  src="/filtermenu.js">` in it, beside v51's `inboxfilter.js` gets a `TypeError` on the
  render that mounts the control — the inbox's whole filter bar, scope switch included,
  gone on the devices least likely to be looked at. `swbump` sees a new file "added
  whole with its callers" and skips it, because the caller it checks for is JavaScript
  and this one is markup.
- **`history.html` is the same pair the other way up**, and harmlessly so: it gained the
  tag, and `history.js` mounts the control only `if (window.beadcause.filterMenu)`. A
  cached page without the file lists the ledger with no filter bar on it, still narrowed
  to whatever the URL asked for, which is the app as it was plus the link still working.
- **`style.css` carries `.filter-text` and `.hist-refused`** — the id box in the panel
  and the daemon's refusal drawn under it. A page cached without those rules draws an
  unstyled input inside a dark panel, which is the white-rectangle-on-black failure
  `appearance: none` is there to prevent.

## What is in it

- `public/filtermenu.js` — new; the collapsing panel, the chips, the summary line and the
  hover-and-tap state machine, shared by the inbox and the History tab. Every word of
  behaviour is the one that was in `inboxfilter.js`, and `test/inboxkinds.mjs` passes
  unchanged over the seam.
- `public/inboxfilter.js` — the inbox's half: the kinds, the counts, the sub-filter, and
  the localStorage they live in.
- `public/history.js`, `public/history.html` — the ledger's four filters (status,
  priority, provenance, an id substring), read from and written to the query string.
- `public/index.html` — the `<script>` tag, before `inboxfilter.js`.
- `public/style.css` — `.filter-text` and `.hist-refused`.
