# v57 — a filter group the old chrome cannot draw (bc-0xil)

The inbox's filter panel gained a bead search box: a text input with a dropdown of
matching ids under it and a pill with an × above it. Three files move together for that,
and every pair of them that a cache can hand out is broken in a different way.

`public/app.js` grew the group and hands it to the panel. `public/filtermenu.js` grew the
thing that draws it — the pills, the dropdown, the arrow keys — as a generalisation of the
text group the History tab has had since v51. `public/style.css` grew `.filter-typeahead`,
`.pill-row`, `.pill-x`, `.suggest` and `.suggest-row`.

**A v56 filtermenu.js beside a v57 app.js draws one bare input and nothing else.** The old
file knows `text: true`, so it builds the box; it has never heard of `suggestions()` or
`picks()`, so typing into it fires the page's search, the answers come back, and nothing
is drawn. There is no error and no gap — a search box that silently ignores every result
is the worst shape this could have taken, because it looks like a tracker with no beads in
it rather than like a stale file.

**A v56 stylesheet beside a v57 pair is worse than unstyled.** `.suggest` is
`position: absolute` and that is load-bearing: it is what makes the dropdown draw *over*
the kind chips instead of pushing them down. Without the rule the list lays out in flow,
the chips slide down under the thumb reaching for them, and on a 393-wide phone the panel
grows past the bottom of the screen with the ones at the end of it unreachable. The input
also loses its `font-size: 16px` inheritance path — `.filter-typeahead` is a flex item and
the wrapper is new — and anything under 16px makes iOS zoom the page in on focus, which
moves an absolutely positioned panel out from under itself. The × goes from a 22px square
to a bare 15px glyph, which is the tap that removes the filter.

The fetch handler is network-first, so these pairs only exist on an offline or flapping
load and heal on the next online one. Bumped anyway, for v56's reason: the cheap half is a
stale *stylesheet*, and a missing stylesheet is not loud.

## The number

This was written as v56 and lost the race to bc-rfnr.9.2, whose own note is the reason
this one is numbered correctly. `const CACHE` merged clean and silent — both branches had
written the same string — and the add/add conflict on `docs/sw-cache/v56.md` was the only
thing that said so. Which is the filename doing exactly the job sw.js's header gives it.
